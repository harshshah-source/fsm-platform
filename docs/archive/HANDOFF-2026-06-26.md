## Repo gotchas (still true — cost real time if unknown)
- **Migrations:** the dev DB user **cannot create a shadow DB**, so `prisma migrate dev` fails (P3014).
  **Hand-author** `prisma/migrations/<UTC-timestamp>_<name>/migration.sql`, then
  `npx prisma migrate deploy && npx prisma generate`. Match the style of recent migrations.
- **Tests are real-DB e2e** (PG16+PostGIS on **5433**). Backend test runner is **vitest**
  (`npx vitest run <pattern>`), not jest. Admin tests run from `apps/admin` (separate vitest).
- **`docs/*` is gitignored** (only `docs/agents/` tracked) — so `docs/progress/*.md` (incl. this file)
  are **local-only**; never `git add -f` them. Tracked planning lives in `.scratch/fsm-platform-v1/`.
- **Bash tool cwd drifts** to `apps/backend` between calls — use absolute paths / `cd` explicitly.
- **Use the Bash tool (POSIX), not PowerShell** for commits — `git commit -F <msgfile>` via a heredoc
  to `$TEMP` avoids quoting breakage. LF→CRLF warnings on `git add` are benign.
- **Whole-file staging only** (`git add -p` unavailable) — plan commits so shared files
  (`app.module.ts`, `AppRoutes.tsx`, `AdminShell.tsx`, `ticketing.module.ts`, `INDEX.md`) land together.
- **TS aliased-condition narrowing** bit once: `const valid = … && x !== '' && …; if (valid) {…}` makes
  TS treat `x` as non-`''` inside the branch — don't then re-compare `x === ''` (dead-comparison error).
