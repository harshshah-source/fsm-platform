# SPINE — how work crosses modules in fsm-platform

Stage A1 · cartographer · 2026-09-02 · evidence static (E2), no browser.
Node = work item in a state. Edge = hand-off with an owner on each end.
Chain verified in code, not docs: AutoPlant telemetry → Ticket → recommender candidate → batch → SE
phone → form → verification → components → warehouse/shadow use → voucher → reports.
Carriers found: 14 cron sweeps, 9 status flips, 3 in-process service calls, 1 outbox, 1 public token,
2 file exports, **3 "a human remembers"** (E-15, E-20, E-26).
`receiver` blank = the finding. `carrier: a human remembers` = C2, never valid.
Severity floor applied: money/stock BROKEN ⇒ S4+DANGEROUS · MANUAL ⇒ S3 · no reverse ⇒ S3.
28 edges. Every row names both module slugs. One id, one price — never price an edge twice.
