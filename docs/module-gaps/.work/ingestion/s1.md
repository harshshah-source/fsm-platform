master-sync). Persona = whoever is harmed when it fails silently. **Operations Head** primary
(fleet-wide truth, owns the Snapshot freshness banner). **Zonal Manager** secondary (their queue
silently empties/floods when device state is stale or unreconciled). See scopeNote in s1.json.
