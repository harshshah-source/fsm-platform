and the escalate/mark-auto-recovery actions. Mobile Verification Result screen is downstream display

## Persona
Zonal Manager, "all day, primary." This module is the judge-of-truth for their zone's field work.

## Goals (3)
1. Triage all verification outcomes for the zone on one page.
2. Investigate + escalate fraud-flagged outcomes (Phase-1 distance delta).
3. Mark CLOSED_AUTO_RECOVERY so auto-recovery is never miscredited as SE repair.
